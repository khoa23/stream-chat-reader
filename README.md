# Đọc comment YouTube

Đọc to live chat YouTube bằng giọng tiếng Việt trong lúc bạn livestream hoặc xem live. Không cần API key.

## Cách dùng

1. Mở `ReadComments.exe`.
2. Dán link livestream hoặc `@tenkenh` vào ô **Link livestream**.
3. Chọn **Nguồn đọc**.
4. Bấm **Bắt đầu**.

Giữ cửa sổ app mở trong lúc dùng. Âm lượng chỉnh được ngay khi đang đọc.

## Nguồn đọc

| Nguồn | Hoạt động | Phù hợp khi |
| --- | --- | --- |
| Microsoft Edge | Online, comment được gửi tới Microsoft | Muốn nhẹ máy nhất |
| VieNeu Nano | Offline, khoảng 400 MB RAM | Muốn đọc nhanh và không gửi comment ra ngoài |
| VieNeu Turbo | Offline, khoảng 1 GB RAM | Muốn giọng tốt hơn, máy còn dư tài nguyên |

Lần đầu dùng VieNeu cần Python 3.10 trở lên và Internet để tải khoảng 1,1 GB. App vẫn cần Internet để lấy chat từ YouTube.
